# Agent instructions

This repo's agent guide is **[CLAUDE.md](CLAUDE.md)**. Read it first. It covers what the
project is, the layout, the commands, and the non-negotiables. Per-area conventions are in
[.claude/rules/](.claude/rules/), and the build record (what is built and what is next) is
[poc.md](poc.md).

The guide is written for Claude Code, but nothing in it is Claude-specific except the
`.claude/` tooling section.
